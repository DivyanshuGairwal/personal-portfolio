## 🛠️ The Tech Stack
I rebuilt this portfolio from scratch to move beyond basic HTML/CSS and dive deeper into modern frontend engineering.

* **React.js** - Component-based architecture for scalable UI.
* **Vite** - Lightning-fast build tool and development server.
* **Tailwind CSS** - Utility-first styling for a custom, premium design system without the bloat of traditional CSS files.
* **Framer Motion** - For smooth, physics-based animations and page transitions.
* **JavaScript (ES6+)** - The core logic powering interactivity.

* **Modern Aesthetic**: Dark theme with glassmorphism, subtle gradients, and clean typography.

## 💻 Running the Project Locally

If you'd like to explore the code or run this on your own machine, follow these steps:

### 1. Clone the repository
```bash
git clone https://github.com/DivyanshuGairwal/personal-portfolio.git
cd personal-portfolio
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start the development server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser to view the application.
